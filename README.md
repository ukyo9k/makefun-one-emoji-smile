One emoji, the one most likely to make a stranger smile: 🌞 (U+1F31E SUN WITH FACE) — warmth itself, a smiling sun offered with no strings attached. A face that reads kind at first glance, a sun that is a good omen in every culture and at every age, a deliberate pick rather than the first smiley that comes to mind, and a sunny greeting that carries no intimacy, sarcasm or flirtation from a stranger.

## Run it

```sh
python3 main.py
```

It writes exactly one emoji — and nothing else — to `/output/entry.txt`.
